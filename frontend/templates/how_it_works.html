{% extends "base.html" %} {% import 'macros.html' as macros %} {% block title %}How It Works · RxRevive{% endblock %} {% block content %} {{ macros.page_header('How It Works', 'The complete ten-step pipeline from upload to downloadable report — the same flow for both engines.') }}
  1. {{ macros.icon('upload') }}

    Upload Resume

    Drag-and-drop a PDF, DOCX or TXT file. Extensions are whitelisted, content is sniffed, filenames are sanitised and the 8 MB limit is enforced.

  2. {{ macros.icon('scan') }}

    Extract Resume Text

    Text is pulled in memory — never written to disk — then cleaned of control characters and collapsed whitespace. Scanned/image PDFs are detected and explained.

  3. {{ macros.icon('doc') }}

    Enter Job Description

    Paste the posting with optional job title and company. Inputs under 80 characters are rejected with clear validation messages.

  4. {{ macros.icon('settings') }}

    Preprocess Text

    Normalisation of unicode punctuation, symbol filtering (keeping C++, C#, .NET intact), tokenisation and built-in stop word removal.

  5. {{ macros.icon('target') }}

    Extract Skills

    150+ curated skills across 8 categories are matched with word-boundary regex in both documents; the JD skill set becomes the requirement baseline.

  6. {{ macros.icon('brain') }}

    Run the NLP Model

    Traditional: TF-IDF (1–2 grams, sublinear TF) → cosine similarity. Transformer: all-MiniLM-L6-v2 → 384-dim embeddings → semantic cosine. Comparison mode runs both.

  7. {{ macros.icon('gauge') }}

    Calculate Matching Score

    Final score = 0.6 × similarity + 0.4 × skill coverage — identical weighting in both engines for fair comparison.

  8. {{ macros.icon('layers') }}

    Compare Requirements

    Experience and education alignment checks, matched/missing skill sets, strengths and gaps spelled out in plain language.

  9. {{ macros.icon('chart') }}

    Generate Results

    Score rings, doughnut charts and model bars drawn with Chart.js from your actual analysis — plus a full suitability summary.

  10. {{ macros.icon('download') }}

    Download Analysis Report

    One click generates your PDF report with ReportLab — stored in your history for later review.

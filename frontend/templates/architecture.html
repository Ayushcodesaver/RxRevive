Codebase structure

Clean separation: routes are thin, engines are swappable, shared logic lives once.

RxRevive/
├── run.py                    ← python run.py
├── backend/
│   ├── app.py                ← application factory + blueprints
│   ├── config.py             ← paths, secrets, upload policy
│   ├── shared/               ← text_extraction · preprocessing · skill_extractor · analysis_helpers
│   ├── traditional_nlp/      ← tfidf_model.py        (Branch A)
│   ├── transformer_nlp/      ← sentence_bert.py      (Branch B)
│   ├── reports/              ← report_generator.py   (ReportLab PDF)
│   ├── database/             ← SQLAlchemy models (User · Analysis · ReportFile)
│   └── routes/               ← main · analysis · reports · authentication · dashboard
├── frontend/
│   ├── templates/            ← 17 Jinja2 templates
│   └── static/               ← css · js (+ vendored Chart.js)
├── datasets/                 ← labelled CSV datasets for Phase-6 evaluation
├── generated_reports/        ← generated PDFs
└── uploads/                  ← temp area (files parsed in memory)

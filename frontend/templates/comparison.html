{{ macros.icon('lock') }} How to interpret the scores

The two scores are not calibrated probabilities and are not directly interchangeable. TF-IDF measures lexical overlap, SBERT measures semantic proximity, and both are combined with skill coverage using the same 60/40 weighting. A 10-point difference means the engines weighted your evidence differently, not that one candidate is “10% more employable”. For the fair evaluation methodology, both engines always receive the exact same resume and job description text, the same skill taxonomy and the same weights.

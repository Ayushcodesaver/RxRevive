{{ macros.icon('brain') }} How this engine works

  1. Extract and preprocess both documents.
  2. Encode each document with all-MiniLM-L6-v2 into dense 384-dimensional embeddings.
  3. Calculate semantic cosine similarity between the embedding vectors.
  4. Extract skills with the same curated taxonomy as the traditional engine.
  5. Identify matched, missing and contextually relevant skills.
  6. Combine semantic similarity (60%) and skill coverage (40%) into the match score.
  7. Generate the semantic analysis report.

RxRevive is an academic final-year project: an intelligent resume and job description matching system built to compare Traditional NLP (TF-IDF) and Transformer NLP (Sentence-BERT) on the same problem statement.

{{ macros.icon('user') }} The team

Team RxRevive — NLP research, backend engineering, frontend & UX, and documentation roles. Individual member details are documented in the project report and viva submission.

{{ macros.icon('target') }} Project purpose

This platform exists for learning, demonstration and academic evaluation. All match scores are educational suggestions — never automated hiring decisions. Messages sent here are stored in the project database for the team to review.
